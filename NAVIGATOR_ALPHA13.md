# Navigator alpha.13

Minecraft Java 26.3 · Fabric Loader 0.20.1 · Fabric API 0.165.0+26.3 · Java 25.

- **Элитры и нагрудник.** По умолчанию клавиша G меняет надетый нагрудник на элитры и обратно. Клавишу можно переназначить в разделе «Элитры и броня». Если G уже занята в Navigator, назначение останется пустым. Снятая вещь занимает ячейку, из которой взяли замену. Смена доступна в выживании и приключении при закрытом инвентаре.
- **Автототем.** Выберите «Всегда» или «Мало здоровья». Второй режим использует настраиваемый порог в сердцах и при желании учитывает поглощение. Предмет из второй руки занимает освободившуюся ячейку тотема. По умолчанию функция выключена. При резком смертельном уроне сервер может применить удар прежде, чем получит смену предмета.
- **Индикатор авторыбалки.** Маленькая удочка с мятной точкой во время рыбалки и серой в ожидании заброса. Значок можно скрыть в настройках рыбалки. Переключение с удочки теперь завершает сеанс без отключения функции. Остановка из-за урона или низкой прочности сопровождается коротким уведомлением.
- **Редактор HUD.** Откройте HUD → Редактор HUD. Перетащите эффекты, список игроков, прочность, стрелы, значок удочки и предупреждения. Колесо меняет масштаб выбранной панели, а «Сброс» возвращает ей исходное положение и размер. Для часов нажмите «Игра» внизу, чтобы переключиться на вид инвентаря. Панели привязываются к краям, если подвести их близко.

Для установки замените прежний Navigator JAR в папке `mods` используемого профиля. Fabric API и настройки сохраняются.
