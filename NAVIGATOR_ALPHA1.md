# Навигатор — 0.1.0-alpha.1

Самостоятельный клиентский мод для Minecraft Java **26.3**, Fabric Loader **0.20.1**, Fabric API **0.165.0+26.3**, Java **25**.

Это первый рабочий срез согласованного проекта, а не весь список будущих функций. Код, предметы, магия, измерения и генерация Admuterion / Abyss в него не включены. Новых игровых объектов или сетевых протоколов мод не регистрирует.

## Установка и управление

Установить только на клиент: JAR Навигатора и Fabric API в папку `mods` выбранного профиля Fabric. На ванильный сервер ничего устанавливать не требуется. Для проверки Навигатора использовать отдельный профиль без Admuterion/Abyss — если оставить их JAR, их контент продолжит загружаться независимо от Навигатора.

| Кнопка по умолчанию | Действие |
| --- | --- |
| Shift + Tab | Меню функций |
| C | Полная видимость |
| X | X-ray |
| P | Список и создание вейпоинтов |
| Удерживать R | Автоматические атаки доступных целей |

Кнопка «Навигатор» также находится в настройках Minecraft. Переназначение клавиш и кнопок мыши — только в меню мода, вкладка «Бинды». Доступны сочетания Shift/Ctrl/Alt; конфликтующие назначения отклоняются. Для быстрого добавления точки и скрытия маркеров можно назначить отдельные бинды. Сообщения мода идут в HUD, в чат мод ничего не пишет.

## Реализовано в этой альфе

- Полное освещение через клиентскую lightmap. Переключаемое удаление тумана, включая водный. Выключение возвращает обычную обработку освещения.
- X-ray: рентген выбранных руд с независимыми переключателями 10 групп, включая глубинные и незерские варианты. После смены режима или списка пересобирается геометрия загруженных чанков. Это режим рентгена; отдельные цветные контуры, объединение жил и ограничения по дистанции ещё не реализованы.
- Вейпоинты: текущая позиция, редактирование имени/координат/цвета HEX, диапазон дистанций от/до, верхняя граница ∞, отключение и удаление. Маркеры отображаются поверх мира при направлении камеры в сторону точки, с подавлением пересекающихся подписей. Одновременно до 32 подписей.
- Сохранение точек по серверу и измерению. Метки смерти: по умолчанию до пяти, срок 20 минут реального времени; количество и срок настраиваются. Смерти далеко ниже нижней границы мира исключаются по координатам; точное распознавание источника «пустота» ещё не добавлено.
- Автобой при удержании бинда: ближайшая видимая доступная цель, обычная дальность, восстановление атаки, поворот к цели. По умолчанию враждебные мобы; атаки игроков включаются отдельно. Попытка прыжкового крита только при проверенной опоре/свободном пространстве и если обычный удар недостаточен по доступному здоровью. Нет автоматического преследования, удержания дистанции или поиска маршрута.
- HUD прочности экипировки и предметов в руках, красная рамка и предупреждение при 10% и ниже; запас стрел.
- Читаемые таймеры эффектов в HUD.
- Список полученных от сервера игроков справа сверху с дистанцией, опциональное уведомление о появлении новых игроков.
- Сохранение конфигурации через временный файл и атомарную замену; резервная копия повреждённых настроек.

Настройки: `config/navigator/settings.json` в каталоге игрового профиля. Редактирование файла вручную не требуется для основных функций.

## Ограничения

X-ray показывает только переданные сервером настоящие блоки; защита от рентгена может скрывать или подменять руды. Чанки за пределами серверной загрузки не появляются. Данные здоровья других игроков не используются как достоверные. Проверка этой редакции проводится на локальном немодифицированном сервере; Java Realms отдельно не проверялся.

Автобой не гарантирует безопасность: игрок самостоятельно управляет перемещением. Открытое меню, смерть или потеря фокуса окна прекращают автоматические атаки. Все размещения, попадания и урон остаются под контролем сервера.

## Следующие согласованные функции

Силуэтная подсветка сущностей и контейнеров; интерфейс друзей; Freecam; траектории снарядов; опасные блоки; выбор инструментов и пополнение хотбара; тотем; быстрая установка; сортировка, избранное и чёрный список; рыбалка; информация о еде; глобальная карта; признаки структур; предупреждение о крипере; сетка спавна; безопасное перемещение автобоя. Эти функции в текущий JAR не заявлены.

## Сборка

```bash
JAVA_HOME=/path/to/jdk-25 ./gradlew build --offline --no-daemon
```

Описание проверок — [VALIDATION.md](NAVIGATOR_VALIDATION.md). Для повторения реального клиентского сценария в подготовленной среде: `python scripts/check_vanilla_client.py` (пути JDK/Xvfb в скрипте относятся к этой среде).
