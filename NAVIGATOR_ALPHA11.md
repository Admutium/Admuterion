# Navigator 0.1.0-alpha.11 — плитки и автоинструмент

Minecraft Java 26.3 · Fabric Loader 0.20.1 · Fabric API 0.165.0+26.3 · Java 25.

## Меню функций

Shift+Tab открывает сетку квадратных плиток в тёмной серо-синей палитре с мятными акцентами. На плитке видны название, значок, переключатель и назначенная клавиша. Нажатие на саму плитку открывает настройки; переключатель меняет состояние отдельно, а нажатие на клавишу позволяет переназначить её. Поиск фильтрует функции по названию и описанию. На небольшом масштабе доступны страницы и прокрутка колёсиком.

Все 15 разделов используют единый стиль: видимость, руды, сущности, контейнеры, траектории, автоинструмент, пополнение, сортировка, автобой, рыбалка, вейпоинты, HUD, игроки, друзья и клавиши. В настройках — переключатели, варианты, ползунки с точным вводом числа, палитра с HEX-кодом и сброс текущего раздела. При достаточной ширине справа показано объяснение функции. У автоинструмента есть собственная наглядная схема.

Анимации появления и переключателей короткие, около 150 мс; их можно выключить через значок настроек главного меню. Они не добавляют задержку игровым действиям. C/X/P/R и Shift+Tab сохраняются. Дополнительные переключаемые функции можно привязать прямо с плитки; по умолчанию новые назначения пустые. Бинды находятся внутри мода.

## Автоинструмент

- Подбор инструмента начинается без искусственной задержки при добыче блока.
- Мечи, копья и булавы в руке по умолчанию не заменяются. Топор доступен для автоматической замены.
- После отпускания ЛКМ возвращается исходная ячейка хотбара. Эту настройку можно отключить.
- Инструмент из основного инвентаря возвращается туда, откуда был взят, а вытесненный предмет возвращается в хотбар. Учитываются износ инструмента и изменение количества вытесненного стака.
- Ручной выбор другой ячейки сохраняется: автоинструмент не перехватывает его до отпускания ЛКМ.
- Закрепление СКМ означает исключение из сортировки. Закреплённые ячейки доступны автоинструменту и пополнению.

При открытом чужом контейнере возврат перестановки откладывается до его закрытия. При несовместимом ручном изменении участвующих предметов возврат отменяется с уведомлением в HUD.

Автостройка и разведка остаются удалёнными. Быстрая разгрузка по аналогам в сундуке в эту версию не включена. Совместимость X-ray с Sodium не менялась. Замените прежний Navigator JAR, сохранив Fabric API; существующие настройки, друзья и точки продолжают использоваться.
