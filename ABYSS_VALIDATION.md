# Проверка Abyss .2 — 2026-11-05

- Чистая сборка Java 25 / Minecraft 26.3 / Fabric прошла. Четыре проверки геометрии: 24 семени, 432 извилистых соединения и 21 168 точек пути; сравнение глубины породы с полным перебором; 800 полостей для проверки разброса высот, размеров, положений и закрытого нижнего диапазона.
- Проверка 1047 JSON-ресурсов: модели, текстуры, каталог, рецепты, переводы и геология. Компас использует lodestone-target; исправлена фаза нарисованных кадров. Облака расположены выше поверхности первого слоя.
- Выделенный сервер: генерация пещер, убежища, лебёдки, растительности, света и руд; естественный потолочный улей; регистрация и предсказание поверхностного спуска; дроп руд; сопротивление породы, TNT/поршни, сохранение; размер вихревика и цикл ауры; урон пчелы +20% без яда; сохранение её привязки к улью и восстановление цели после временной неуязвимости; второй слой закрыт.
- В полных сетевых прогонах .2 два настоящих клиента прошли старые сценарии до стадии 14: отмена и одновременность спуска, разные точки возврата, компас, подъём/спуск/отцепление крюка, общая волна и защита убежища.
- Финальный фокусный сетевой прогон `run/abyss-network-logs-1793912130` проверил новые сценарии: первый импульс ауры — ровно 5 HP на Hard; нейтральность и ответ пчелы на реальную атаку; выпуск колонии block entity улья; выход через естественную световую шахту на реальную поверхность Верхнего мира с соответствующими X/Z; восстановление обычной гравитации.

Фокусный прогон запускается через `ADMU_ABYSS_QUICK=1 python3 scripts/test_abyss_network.py`. Полный прогон — той же командой без переменной. Компиляция сериализована до запуска трёх игровых процессов; сценарий ждёт завершения загрузки измерения обоими клиентами. Фокусный прогон не повторяет старые стадии 0–14. Сообщение PASS в тестовом обработчике перечисляет общий набор сценариев, поэтому для объёма конкретного запуска следует смотреть этот отчёт и номера стадий в логе.

Проверки не заменяют длительное выживание. Графические клиенты работали с программным драйвером; это не оценка FPS на игровом компьютере. Читаемость маршрутов и баланс требуют пользовательского прохождения. Для .2 нужен новый мир: версия и высота генератора изменились.
