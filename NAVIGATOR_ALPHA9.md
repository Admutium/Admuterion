# Navigator 0.1.0-alpha.9 — сортировка

Minecraft Java 26.3 · Fabric Loader 0.20.1 · Fabric API 0.165.0+26.3 · Java 25.

## Кнопки

В обычном инвентаре появилась кнопка «Сортировать» над панелью. В стандартном интерфейсе сундука справа две независимые кнопки:

- «Инвентарь» сортирует только собственные ячейки игрока.
- «Сундук» сортирует только ячейки открытого контейнера.

Во время работы выбранная кнопка меняется на «Стоп», другая временно недоступна. Сортировка работает постепенно, обычными серверными действиями с ячейками, без команд, выбрасывания и Shift-переносов между сундуком и игроком.

## Порядок и защита

Совместимые стаки объединяются до допустимого размера. Затем предметы группируются по типу (внутреннему идентификатору Minecraft), пустые ячейки уходят в конец. Разные компоненты, имена, зачарования и повреждения не объединяются в один стак.

Защищённые ячейки своего инвентаря пропускаются. Хотбар по умолчанию сохраняется, броня, вторая рука и сетка крафта не сортируются. Если хотите включить хотбар: Shift+Tab → Функции → Пополнение / рыбалка → «Сортировать также хотбар».

Сначала уберите предмет с курсора. Ручное действие с ячейкой, нажатие клавиши, закрытие или смена интерфейса останавливают очередь. При заметном расхождении содержимого с ожидаемым очередь тоже останавливается. Если из-за серверной коррекции предмет остался на курсоре, его нужно положить вручную; мод не пытается выбросить его или переместить в другую область.

## Другие игроки

Мод работает только с собственными доступными ячейками игрока и открытым им стандартным контейнером. Инвентари других игроков не перебираются и не изменяются. Сортировка сундука не перемещает предметы в свой инвентарь; сортировка своего инвентаря не перекладывает вещи в сундук.

Общий сундук содержит общие предметы: новый порядок виден всем. Операция не является серверной атомарной блокировкой сундука; одновременное перекладывание другим игроком может остановить сортировку. Плагиновые меню с нестандартными правилами и инвентарями игроков не поддерживаются.

Поддержаны обычный инвентарь выживания и стандартные меню сундуков, включая двойные. Кнопки не добавляются в печи, верстаки, торговлю и творческий инвентарь. Другие функции alpha.8 сохранены.

Заменить предыдущий JAR, оставить Fabric API. Совместимость X-ray с Sodium не менялась.
