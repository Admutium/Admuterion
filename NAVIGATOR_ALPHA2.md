# Навигатор 0.1.0-alpha.2

Minecraft Java **26.3**, Fabric Loader **0.20.1**, Fabric API **0.165.0+26.3**, Java **25**. Только клиент; сервер остаётся ванильным.

## Функции приоритетов 7–10

### Руды — 10

По X включается выбранный режим: X-ray, цветные контуры через стены или их сочетание. В меню «Руды → Режим, дистанции и цвета» настраиваются нижняя/верхняя границы дистанции **контуров**, число отображаемых объектов и объединение соседних блоков одинаковой руды в жилы. Цвет каждой группы задаётся HEX. X-ray сохраняет показ выбранных руд во всех загруженных чанках; границы контуров не ограничивают его геометрию.

В режиме жил рамка охватывает всю связанную группу; для точного положения каждого блока можно отключить объединение. Поддерживаются все согласованные ванильные руды и глубинные/незерские варианты.

Индекс строится постепенно по палитрам секций, без сканирования мира каждый кадр. Обрабатывается до трёх секций за тик с мягким бюджетом 2,5 мс; одна секция завершается целиком. Кэш ограничен 1024 чанками, кандидаты для группировки — 4096 блоками, число контуров — настройкой 16–512. Изменённые и добытые блоки обновляются по клиентским и серверным сообщениям; выгруженные чанки удаляются. Положение рамок пересчитывается раз в десять тиков.

### Снаряжение и HUD — 9

Прочность отображается прямо на иконках инструментов/брони, включая хотбар и инвентарь. При 10% и ниже появляется красная рамка. Отдельная панель экипировки перенесена выше хотбара, чтобы не пересекаться с запасом стрел; предупреждение остаётся видимым. Панель и цифры на иконках отключаются независимо.

### Сущности — 8

Силуэтный контур модели через стену, а не коробка ESP. Можно отдельно включать игроков, враждебных мобов и остальных живых существ, задавать дальность и видимость через препятствия. Друзья выделяются зелёным.

Подписи имеют фон, регулируемый размер, ограничение числа и подавление наложений; можно отключать имена, здоровье и расстояние. Обычные подписи выбранных сущностей скрываются, чтобы не дублироваться.

Здоровье мобов берётся из синхронизированных данных. Для игроков используются доступные серверные оценки из табло здоровья/сердечек; без таких данных показывается `? HP`. Произвольные серверные табло могут иметь собственную семантику — скрытое здоровье мод не вычисляет. В меню есть список друзей по UUID и удаление сохранённых друзей.

### Траектории — 8

Лук при натяжении, снежки и эндер-жемчуг. Учитываются сила натяжения, гравитация, сопротивление воздуха/воды и движение стрелка. Линия останавливается на ближайшем столкновении с блоком или существом; отмечается точка столкновения. Показ через стены и каждый тип предмета переключаются отдельно.

Прогноз номинальный: случайный разброс, движение цели после выстрела и задержка сети меняют результат. Маркер жемчуга показывает столкновение, а не гарантированно безопасное место телепортации. Незагруженная территория не прогнозируется.

### Контейнеры — 7

Контуры фактической формы через стены. Сундуки и бочки жёлтые, ловушки красные, эндер-сундуки фиолетовые, шалкеры лиловые. Двойной сундук получает одну общую рамку. Есть выбор категорий, цветов, дальности и слабой заливки. Содержимое закрытых контейнеров не раскрывается.

### Автовыбор инструмента — 7

Режимы хотбара и всего инвентаря. При начале добычи выбирается инструмент с подходящим уровнем для дропа и лучшей скоростью; учитываются эффективность, предпочтение удачи/шёлка для руд и минимальная прочность. Перестановки используют обычный протокол инвентаря, не создают копий предметов. При перестановке из основного инвентаря добыча кратко приостанавливается для синхронизации; при несоответствии выбранного предмета операция прекращается по тайм-ауту. В открытых контейнерах автоперестановок нет.

### Автобой — 7

По-прежнему работает только при удержании R. Подход к цели включается **отдельно**, по умолчанию выключен. Используются обычные клавиши движения и проверка ровного загруженного маршрута: сплошная опора, свободное место, отсутствие жидкостей/опасных блоков и мешающих живых существ. Перед движением дополнительно проверяется участок впереди. Ручное движение имеет приоритет.

Поиск маршрута ограничен 16 блоками по горизонтали и 768 узлами. Переходы по лестницам, перепады высоты и прыжки через разрывы не поддерживаются: при отсутствии безопасного ровного пути мод останавливается. На слишком близкой дистанции ищет безопасное отступление. Обычные атаки и прыжковые криты сохраняют серверную дальность и восстановление удара. Никакого полёта, отмены урона или изменения серверных характеристик нет.

Проверки пути уменьшают риск, но не гарантируют защиту от чужих ударов, движущихся существ, скольжения, внезапных изменений блоков или сетевых задержек. Игрок контролирует ситуацию.

### Видимость и метки смерти — 7

Полная видимость C сохранена. Метки смерти теперь дополнительно используют причину смерти из серверного сообщения: подтверждённая смерть от пустоты не создаёт метку даже на обычной высоте. При отсутствии причины сохраняется проверка глубины. Срок и число меток настраиваются в HUD.

## Управление и обновление

Заменить alpha.1 на alpha.2 в `mods`, оставить Fabric API. Не держать две версии Навигатора одновременно. Новый мир не нужен; настройки первой альфы автоматически дополняются новыми полями.

Shift+Tab открывает меню; все назначения меняются только там. C — свет, X — руды, P — точки, удерживать R — бой. Новые настройки разбиты на страницы, чтобы оставаться доступными при небольшом размере интерфейса. Сообщения мода остаются в HUD.

Проект независим от Admuterion/Abyss. В отдельном профиле не должно быть их JAR, если их контент не нужен.
