# Навигатор 0.1.0-alpha.3

Minecraft Java 26.3, Fabric Loader 0.20.1, Fabric API 0.165.0+26.3, Java 25.

- X-ray переключает отрисовку без пересборки обычных чанков. Руды рисуются отдельным кэшем настоящих моделей; возвращение обычного мира также не требует пересборки. Кэш прогревается в фоне, когда X-ray выключен. Новые загружаемые чанки добавляются постепенно.
- В настройках руд можно ограничить число моделей: 256–8192, по умолчанию 2048. Контурный режим сохранён.
- Подсветка сущностей ограничена объектами клиентского мира. Это важно для хоста LAN, где сервер и клиент выполняются в одной Java-машине. Серверные флаги свечения, блоки и цвета команд не изменяются модом.
- Автоподход учитывает сближение цели, раньше отступает и не планирует прыжковый крит на ходу навстречу приближающемуся врагу. Скользкий пол исключён из безопасного маршрута. Спринт не используется.

Управление прежнее: Shift+Tab, C, X, P, удержание R. Заменить предыдущий JAR, оставить Fabric API; новый мир не нужен.

## Проверено

Сборка и 12 JUnit-тестов. Настоящий интегрированный LAN-хост с Navigator и отдельный клиент-наблюдатель без Navigator: наблюдатель видит обычную стену, пока хост видит руду и силуэты за ней. При переключениях X счётчик полной пересборки чанков не увеличивается. Серверные блоки, флаги свечения и цвета сущностей остались исходными.

Эта проверка касается локальной графики. Другие игроки видят обычные действия персонажа, включая перемещение и атаки. Realms, сторонние рендеры/шейдеры и совместимость с античитами не проверялись. X-ray использует только присланные сервером блоки. Автобой не гарантирует отсутствие урона при любых условиях.

Проверка против трёх активных зомби: все побеждены, минимум здоровья 17.5/20. Критерий полного отсутствия урона не пройден; персонаж всё ещё может пропустить удар. Это ограничение сохранено в отчёте.
