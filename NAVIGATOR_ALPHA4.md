# Navigator 0.1.0-alpha.4

Minecraft Java 26.3 · Fabric Loader 0.20.1 · Fabric API 0.165.0+26.3 · Java 25.

- Вейпоинты привязаны к проекции камеры текущего кадра. Убрана отдельная проекция по обновляемым 20 раз в секунду координатам и углам игрока, из-за которой маркеры дёргались при движении. Учитывается реальное поле зрения камеры.
- В меню «Сущности» отдельные разделы «Игроки» и «NPC и мобы». Настройки игроков и друзей сохранены.
- Для NPC — контуры силуэтов, по умолчанию без подписей. Можно включить маленькие подписи, здоровье и дистанцию, настроить размер и лимит подписей. Дальность и видимость через стены независимы от настроек игроков.
- Мирные/нейтральные существа включаются отдельно от враждебных. Исходные цвета: тёплый жёлтый и красный; оба настраиваются через HEX. При отключённых подписях NPC скрываются также стандартные имена выбранных существ.
- Инструмент, взятый автосменой из основного инвентаря, возвращается в исходную ячейку после прекращения добычи; заменённый предмет возвращается в хотбар. Перед займом следующего инструмента предыдущая перестановка отменяется. Возврат работает и с исходно пустой рукой, и при поломке инструмента. Если игрок сам изменил участвующие ячейки, автоматический возврат отменяется с HUD-уведомлением. При открытом меню возврат откладывается до закрытия.

Заменить старый JAR, оставить Fabric API. Мир и настройки сохраняются. C/X/P, Shift+Tab и удержание R без изменений. Чат модом не используется.

Пределы: подсветка и вейпоинты используют только загруженные сервером данные. Нейтральные существа относятся к мирной группе даже после провокации. Возврат инструмента не переупорядочивает другие ячейки и не отменяет ручные изменения инвентаря.
