# Navigator alpha.22

Карта по **M** открывает измерение игрока. Вкладки позволяют просматривать сохранённые участки Верхнего мира, Незера и Энда в любом из этих измерений. При первом открытии другой вкладки карта центрируется на последней сохранённой позиции в этом измерении. Метки остаются привязаны к своему измерению.

В режиме **Авто** под каменным сводом карта переключается на срез по высоте ног игрока. На открытом воздухе показывается поверхность. В Незере по умолчанию открывается срез, в Энде — поверхность. Распознавание пещеры ориентируется на форму естественного свода рядом с игроком. Режим можно выбрать вручную кнопкой слева вверху.

- **Колесо** меняет масштаб.
- **Ctrl + колесо** меняет глубину. Шаг по умолчанию — четыре блока.
- **Page Up / Page Down** сдвигают срез на один блок.
- **Home** возвращает срез на высоту игрока в текущем измерении.
- **O** или шестерёнка открывают настройки карты. Клавиши глубины, шаг прокрутки и автопереключение настраиваются там же.

На срезе светлее показан пол открытых проходов, темнее — порода, а вода, лава и пустота имеют отдельные цвета. Вейпоинты на срезе ставятся на доступный пол. Поверхность под деревьями сохраняется отдельно от крон. Кроны можно скрыть в настройках.

Старый кэш поверхности читается. Срезы и разделение земли и крон появляются после обновления соответствующих чанков. Для измерения без сохранённых участков карта покажет пустую сетку до первой загрузки чанков этого измерения.
