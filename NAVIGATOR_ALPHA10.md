# Navigator 0.1.0-alpha.10 — уборка и интерфейс

Minecraft Java 26.3 · Fabric Loader 0.20.1 · Fabric API 0.165.0+26.3 · Java 25.

## Удалены автостройка и разведка

Из основной сборки полностью убраны автоматическое строительство, призрачная разметка, каталог строительных материалов, подсветка полостей/шахт и распознавание структур. Удалены их кнопки, HUD, настройки и фоновые сканеры. Сохранён поиск руд и контейнеров, который используется работающими функциями.

Старые параметры этих двух экспериментальных функций в существующем JSON игнорируются и исчезнут при следующем сохранении настроек. Остальные настройки, бинды, друзья и вейпоинты сохраняются.

Исходники до удаления сохранены локально в git-ветке `archive/build-survey-alpha9`, исходный коммит `44d6fe5`. Старые схемы не выдаются за рабочие и не загружаются в новый JAR. Для возвращения функций потребуется отдельная переработка и проверка в обычной игре.

## Компактная сортировка

Большие внешние кнопки заменены значками «≡» размером 14×12 у соответствующих областей:

- у верхней области сундука — сортировка сундука;
- у области собственного инвентаря — сортировка своих ячеек.

При наведении появляется подсказка. Во время сортировки значок меняется на «×» для остановки. Кнопки следуют за положением панели, включая переключение книги рецептов. Логика объединения стаков, защищённых ячеек и разделения сундука/инвентаря сохранена.

## Средняя кнопка в креативе

В творческом режиме мод больше не перехватывает СКМ для переключения защиты ячейки и не рисует её золотую рамку. Ванильные выбор блока в мире и клонирование стака в творческом инвентаре работают обычным образом. Сохранённый список защищённых ячеек не стирается при смене режима.

В выживании СКМ по ячейке своего инвентаря продолжает переключать защиту. Сортировка, пополнение, рыбалка, HUD, вейпоинты и остальные рабочие функции сохранены.

Заменить предыдущий JAR, оставить Fabric API. Совместимость X-ray с Sodium не менялась.
