# Admuterion 0.1.0-preview.4 — на пользовательский тест

Minecraft 26.3 · Fabric Loader 0.20.1 · Fabric API 0.165.0+26.3 · Java 25.

Нажмите Download raw file на JAR, замените предыдущий JAR Admuterion в mods. Fabric API оставить. Не распаковывать.

Изменения: заголовки установок без слова «ядро», центрирование и разнесённые подписи/слоты; обычный survival-инвентарь в палитре мода; текущее HP/питание без максимума; собственные непрозрачные текстуры; общая рамка и знаки на гранях собранного многоблока, звук активации и снятие рамки при разборе.

Новые сооружения: Пресс (слиток железа/меди → пластина, 200 тиков, 8 запусков на катализатор) и Катализаторный пресс (6 обычных углей → катализатор, 200 тиков, 8 запусков на заправку катализатором). Новые ядра используют тот же корпус 3×3×3. Железные пластины дают альтернативный рецепт восьми производственных корпусов, медные — восьми деревянных корпусов. Старые рецепты оставлены.

Средоточие: новые постройки привязаны к центру чанка — внутренние X/Z 7 и 8; первое ядро задаёт нижний Y центрального объёма 2×2×2. Старые склады не переносятся. Чёткие линии вместо частиц показывают центральный чанк и всю область 5×5, в том числе при удержании ядра внутри существующей области. Новые производственные ядра нельзя размещать так, чтобы объём сооружения касался внешнего края области: оставляется один блок отступа.

Боковая панель Средоточия показывает сооружения загруженной части области, обновляется при открытии. Чанки принудительно не загружаются; до 128 записей. Поиск не добавлен — он остаётся будущим открываемым улучшением.

Сборка прошла. Выполнена короткая проверка новых прессов/рамок/границ, клиент загружен. Дополнительные игровые проверки остановлены по просьбе пользователя. Полная игровая приёмка — пользователем.
