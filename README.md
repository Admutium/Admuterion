# Admuterion 0.1.0-preview.5 — на пользовательский тест

Minecraft 26.3 · Fabric Loader 0.20.1 · Fabric API 0.165.0+26.3 · Java 25.

Замените предыдущий JAR Admuterion в папке mods, Fabric API оставьте. JAR не распаковывать. Перед проверкой существующего мира сохраните его резервную копию: изменены данные обработки и интерфейсы хранилища.

## Что добавлено

- Автосборка производственных сооружений из корпусов в инвентаре после размещения ядра. Уже установленные корпуса засчитываются. При недостатке материалов или защищённом препятствии строительство не расходует ресурсы. Допустимые растения и грунт разрушаются с обычными выпадениями; древесина, камень, руды, контейнеры и сооружения не сносятся автоматически.
- Средоточие достраивается при четырёх нижних ядрах над четырьмя корпусами либо при всех восьми ядрах. В первом случае в инвентаре нужны ещё четыре ядра. Новое Средоточие можно строить только в Верхнем мире, в центре чанка. Старые склады не перемещаются.
- Три одноблочных стола: улучшений, рецептов мода и характеристик персонажа. Стол улучшений показывает стоимость зелёным/красным, расходует материалы из инвентаря, выдаёт модуль туда же. Без места под результат крафт запрещён. Инвентарь на экране стола не отображается.
- Модули устанавливаются через боковую кнопку в интерфейсе сооружения. Она появляется после использования стола улучшений, при наличии совместимого модуля в инвентаре или установленного модуля. Одна ячейка на категорию; T2 заменяет T1, а его рецепт использует T1. Подсказки показывают совместимость и ограничения.
- Скорость T1/T2: +25/+50% к скорости выполнения; энергоёмкость: 12/18 катализаторов вместо базовых шести; экономия энергии: 5/10%; плавильня: два/три параллельных рабочих слота; автоподача: буфер одного/двух стаков; извлечение дробилки: четыре руды дают семь/восемь измельчённых вместо базовых двух в три. Стоимость и результат видны в столах. Модули нельзя извлекать, если это потеряет занятые слоты/энергию или изменит уже оплаченную обработку.
- Катализатор сразу преобразуется в 64 энергии, если помещается целиком. Базовый запас — 384. Интерфейс показывает текущую и максимальную энергию, причину остановки, фильтр рецепта и отдельные полосы параллельной обработки. Дробные затраты сохраняются.
- Поиск Средоточия открывается отдельным модулем. Четыре страницы заменяются строкой поиска и прокруткой тех же 216 слотов. Индекс обновляется при изменении склада; при вводе не пересканируется мир. В сетевом индексе передаются названия без тяжёлого содержимого предметов.
- Модуль возрождения из кровати: персональный переключатель с кроватью в Средоточии. После смерти выбирается безопасная точка в одном-двух блоках снаружи сооружения. При отсутствии целого Средоточия, модуля или безопасного места остаётся обычное возрождение. Ванильная кровать не перезаписывается.
- Аметистовые кожаные сапоги: +15% скорости передвижения, защита и прочность кожаных. Стол характеристик показывает параметры именно открывшего его игрока, включая скорость атаки и добычи.

## Культиватор

Куб 3×3×3 из ядра в центре и 26 производственных корпусов. Обрабатывает один слой в квадрате 11×11, кроме собственной площади 3×3: крайние корпуса действуют на четыре блока наружу. Рабочий слой выбирается по окружающей земле; сооружение может стоять на земле или быть вкопано на один, два или три блока. При недопустимой высоте строительство отклоняется. Для пересекающихся рабочих областей разница высот слоёв должна быть не меньше 10 блоков.

Работает с пшеницей, морковью, картофелем и свёклой. Семена/овощи кладутся во входные слоты, урожай — в выходные. Стоимость: вспахивание 1, увлажнение 1, продление влажности 1, сбор урожая 2, посадка 1 энергии. Базовый интервал — два тика на действие; это не мгновенная обработка всего поля. Природная вода и дождь увлажняют бесплатно. При сборе резервируется семя на следующую посадку. Причина остановки и рабочая высота отображаются в интерфейсе. Значения доступны в конфигурации баланса.

## Проверки и границы версии

Финальный Gradle build успешен, четыре существующих JUnit-теста пройдены. Выполнен короткий запуск выделенного сервера до состояния Done. Подробные игровые/графические испытания новых функций не выполнялись по просьбе пользователя; эта версия передаётся ему на проверку. Проверки предыдущих редакций не считаются проверкой всех новых функций.

Трубы и транспортная логистика отложены. Стол рецептов показывает поставляемые рецепты мода, без скрытых исследований; внешние рецепты модов/датапаков автоматически в этот каталог не включаются. Поиск не увеличивает ёмкость склада. Текстуры остаются предварительными; пометки об этом находятся вне игры.
