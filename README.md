# Admuterion 0.1.0-preview.2

Исправлен клиентский краш: удалена инъекция в отсутствующий Minecraft.setScreen. Открытие установок через инвентарь использует Fabric ScreenEvents.

Minecraft 26.3, Fabric Loader 0.20.1, Fabric API 0.165.0+26.3, Java 25. Удалите старый JAR Admuterion из mods и установите только preview.2 вместе с Fabric API. Распаковывать JAR не нужно.

Это промежуточная сборка, не полная 0.1.0. Реализованы катализатор, начальные железная/медная цепочки, корпуса и ядра двух установок. Средоточие, HUD, характеристики и игровая система питания ещё не реализованы.

Чистая сборка и четыре расчётных теста прошли. Полная игровая проверка GUI ещё не выполнена.
