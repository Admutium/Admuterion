# Admuterion 0.1.0-preview.6 — трубы и лимиты урожая

Minecraft 26.3 · Fabric Loader 0.20.1 · Fabric API 0.165.0+26.3 · Java 25.

Замените старый JAR Admuterion в mods; Fabric API оставьте. JAR не распаковывать. Перед тестом существующего мира сохраните резервную копию.

## Трубы

Новая медная предметная труба: собственная полая модель, стеклянные стенки, медные обоймы с заклёпками и небольшими следами патины. Текстуры предварительные; эта пометка находится только в документации/коде. Соединяется прямо, поворачивает и идёт вертикально. Тройники и перекрёстки запрещены. Добавление трубы с третьим соединением отклоняется; недопустимые линии, созданные перестройкой окружения, останавливаются с причиной в настройках.

Рецепт: верхний и нижний ряд по три медных слитка, средний ряд — три стекла; результат 12 труб.

Линия соединяет два сооружения мода внутри территории одного целого Средоточия. Она может связать склад со станком или два станка. К Средоточию и станкам можно подключаться через поверхность корпуса. Кольца, сторонние сундуки и линии длиннее 128 труб в этой редакции не поддерживаются. Чанки принудительно не загружаются; выгруженный участок приостанавливает перенос.

Трубы двусторонние. По умолчанию склад подаёт подходящее сырьё и катализаторы, станок отдаёт продукцию. Переносится один предмет за отправку, несколько предметов могут одновременно двигаться в обе стороны. Предметы видны внутри трубы, но не являются выброшенными предметами и не подбираются.

Скорость — один блок за восемь тиков. Каждый предмет занимает 2 единицы транспортной мощности до доставки; сама труба мощности не занимает. Общий транспортный лимит — 100 на Средоточие, то есть до 50 предметов в пути на базу. Более длинные маршруты дольше удерживают резерв.

**Граница редакции:** это учёт транспортной мощности. Производственные станки пока сохраняют систему катализаторов preview.5; переход на общий бюджет со значениями плавильни 80, культиватора 80, дробилки 50, приоритетами станков и пятисекундным удержанием ещё не включён. Транспорт не выдаётся за реализацию всей новой энергосистемы. Ретрансляторы также пока не добавлены.

До отправки резервируется подходящее место назначения. В пути предмет принадлежит одной трубе и сохраняется вместе с ней. При разрыве маршрута выполняется возврат в исходный слот; если тот занят, предмет остаётся в трубе до возможности возврата. Разрушение владеющей трубы выбрасывает её содержимое однократно. При уничтоженном источнике невозвращаемый предмет выбрасывается у владеющей трубы.

## Настройщик связей

Рецепт: строки « CC», « SC», «S  », где C — медный слиток, S — палка. Это три слитка и две палки.

- ПКМ настройщиком по трубе открывает интерфейс. Сначала выберите сторону подключения.
- Режим: оба направления, только приём, только отправка, отключено. Приём/отправка указаны относительно подключённого сооружения.
- Назначение: автоматически, сырьё, катализаторы, продукция. Автоматический режим отдаёт продукцию и принимает подходящие материалы. Режим «сырьё» позволяет также извлекать входное сырьё вручную заданным маршрутом; «продукция» не разрешает вставлять вещи в выходные слоты станка.
- Фильтр: щелчок предметом на курсоре по образцу либо Shift + щелчок по предмету в инвентаре. Предмет не расходуется. Пустой образец пропускает все подходящие предметы.
- Приоритет линии: низкий, обычный, высокий. Равноприоритетные линии обслуживаются по очереди; высокая непрерывная нагрузка может задерживать низкую.
- Shift + ПКМ настройщиком быстро переключает режим подключения.
- При наведении на трубу с настройщиком видны стрелки входа/выхода.

## Лимиты культиватора

В интерфейсе культиватора кнопка «Лимиты» открывает отдельные настройки пшеницы, моркови, картофеля и свёклы. Окно также открывается настройщиком по культиватору/его корпусу. Введите число и нажмите галочку. Пустое поле — без лимита; 0 — не собирать данную культуру. Максимальное вводимое значение — 1 000 000.

При лимите 200 и 250 моркови в Средоточии морковь не собирается. После снижения запаса ниже лимита сбор возобновляется. Излишки сохраняются. Остальные культуры работают по собственным ограничениям. Учитываются также урожай на выходах культиваторов и предметы в пути, чтобы несколько сборщиков не продолжали производить уже ожидающий доставки запас.

Лимит останавливает следующую операцию сбора, а не обрезает обычные выпадения: последний сбор может немного превысить заданное количество. Лимит не запрещает игроку самостоятельно складывать больше вещей. При включённом лимите и недоступном Средоточии сбор этой культуры останавливается с объяснением; вспахивание, посадка и увлажнение сохраняют свои правила.

## Проверено

Gradle build успешен, четыре существующих JUnit-теста пройдены. В отдельном серверном мире короткий сценарий подтвердил: подключения через корпуса, двусторонний перенос по одному предмету, сохранность количества при переработке и разрыве линии, сохранение/чтение предметов в пути, возврат продукции в склад, остановку моркови при 250/200 и сбор с повторной посадкой после снижения до 199.

Подробные игровые и визуальные проверки оставлены пользователю. Проверка реального одновременного подключения нескольких клиентов в эту редакцию не входит.
