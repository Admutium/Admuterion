# Admuterion 0.1.0-preview.3

Minecraft 26.3 · Fabric Loader 0.20.1 · Fabric API 0.165.0+26.3 · Java 25.

Скачать JAR кнопкой Download raw file. Удалить предыдущий Admuterion JAR из mods, положить preview.3 и оставить Fabric API. Не распаковывать.

Добавлено: полосы HP/брони/питания (в survival); два HUD с переключателем в Options; HP/урон/лечение ×5; фиксированная броня; питание 100 без saturation, естественная регенерация; Средоточие 4×4×4 с общими 216 слотами; территории 5×5 чанков и подсветка; отдельные экраны установок с прогрессом/энергией; строительство без Shift; вкладка на первой странице; Hard для новых миров.

Средоточие: сначала первое ядро как нижний угол центрального объёма 2×2×2, затем ещё семь ядер в положительных направлениях X/Y/Z; снаружи 56 деревянных корпусов. Общий склад открывается через E, четыре страницы по 54. Первое ядро резервирует территорию; удаление последнего освобождает её.

Баланс в config/admuterion-balance.json; выбор HUD в config/admuterion-client.properties.

Проверены build, расчётные и серверные сценарии, клиентский запуск и компактный HUD. Полная ручная игровая приёмка остаётся пользователю; дополнительные подробные тесты остановлены по его просьбе. Текстуры временные. Это редакция для проверки, не окончательно принятый релиз.
