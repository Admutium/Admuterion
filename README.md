# Admuterion 0.1.0-preview.1

Промежуточная сборка. Minecraft 26.3, Fabric Loader 0.20.1, Fabric API 0.165.0+26.3, Java 25.

Откройте JAR в GitHub и нажмите Download raw file. Положите в mods вместе с Fabric API. Распаковывать не нужно.

Это не полная 0.1.0: есть катализатор, начальные железная/медная цепочки, корпуса и ядра двух установок. Средоточие, HUD, характеристики и игровая система питания ещё не реализованы. Сборка и четыре расчётных теста прошли; проверена загрузка dedicated server. Клиент и GUI пока не проверены.

Эта ветка содержит только опубликованную тестовую сборку, контрольную сумму и описание, без исходников или workflows.
