# Navigator 0.1.0-alpha.8 — форма и материал

Minecraft Java 26.3 · Fabric Loader 0.20.1 · Fabric API 0.165.0+26.3 · Java 25.

## Как выбрать

Shift+Tab → Функции → Строительство:

1. «Форма»: площадка 5×5, стена 5×3 или ограда 7×7.
2. «Материал»: выберите строительный блок. Для площадки и стены есть быстрый выбор булыжника, группы досок, камня/кирпича, цветных блоков и фильтр доступного в инвентаре. Для ограды список содержит виды заборов.
3. Выберите поворот и нажмите «Разметить у блока прицела».
4. Проверьте материалы, выберите режим и нажмите «Старт / продолжить».

В списке показано: доступно в незашищённых ячейках / нужно для новой формы. Площадке требуется 25 блоков, стене 15, ограде 24. Выбирать можно и материал, которого пока нет: перед автостройкой наличие проверяется заново.

## Доступные материалы

Для площадок и стен — виды досок, включая бамбуковые доски и мозаику; булыжник, камень, кирпичи и поддержанные варианты глубинного сланца, туфа, гранита/диорита/андезита, песчаника, чернокамня, эндерняка и адского кирпича; шерсть, бетон и обычная окрашенная терракота.

Для ограды — деревянные заборы разных пород и забор из адского кирпича. Ступени, плиты, калитки, стекло, падающие блоки и механизмы не входят в этот список.

Выбор конкретный: например, еловая стена расходует еловые доски. Дубовые или берёзовые доски вместо них не подставляются. Защищённые ячейки не расходуются. Автостройка может перенести подходящий стак из основного инвентаря в свободную ячейку хотбара.

## Сохранение выбора

Материал сохраняется отдельно для каждой формы. Можно оставить булыжник для площадки, еловые доски для стены, берёзовый забор для ограды. Сохраняются также последняя выбранная форма и поворот.

Новый выбор применяется только при создании новой разметки. Текущая разметка остаётся из ранее выбранного материала, пока вы её не создадите заново. Уже поставленные блоки автоматически не заменяются.

## Ограничения автостройки

Размеры трёх форм и ограничения alpha.7 сохранены: подготовленный ровный пол, движение снаружи разметки, обычная досягаемость, пауза по препятствию/урону/ручному управлению. Произвольных размеров, новых ферм, выкапывания, лесов и импорта схем в этом обновлении нет.

Заменить старый JAR, оставить Fabric API; новый мир не нужен. Совместимость X-ray с Sodium не менялась.
